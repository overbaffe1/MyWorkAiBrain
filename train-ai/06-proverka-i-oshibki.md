# 06. Проверка и грабли

## Чек-лист перед сдачей

1. **Каждая модель:** `[model] key: … KB, ~… tris, … bones, …s loop` — размер ≤ ~1.6 МБ, треугольников ≤ ~30 тыс.
2. **Раскадровка анимации** (`anim_preview.py`) просмотрена глазами: движение видно, детали читаемы, ничего не
   улетает за кадр, цикл замкнут (первый и последний кадр совпадают), кадр 0 — красивый постер.
3. **glb содержит анимацию:**
   ```python
   import json, struct
   b = open("models/glb/chest.glb", "rb").read(); n = struct.unpack("<I", b[12:16])[0]
   g = json.loads(b[20:20 + n])
   print([(a["name"], len(a["channels"])) for a in g["animations"]], [len(s["joints"]) for s in g["skins"]])
   # ожидается ОДНА анимация и ОДИН skin
   ```
4. **pptx валиден и анимации на месте:**
   ```python
   import zipfile; from lxml import etree
   z = zipfile.ZipFile("exports/cantillon-3d-presentation.pptx")
   for i in range(1, 11):
       s = z.read(f"ppt/slides/slide{i}.xml"); etree.fromstring(s); s = s.decode()
       print(i, "embedAnim" in s, 'presetID="100"' in s)    # модель с анимацией + авто-«Сцена»
   from pptx import Presentation; Presentation("exports/…pptx")   # открывается python-pptx
   ```
5. **PNG-превью всех слайдов** просмотрены (сеткой 2×5): переносы заголовков, наложения, мелкий текст.
6. Текст выступления и источники обновлены под новую нумерацию слайдов.
7. Закоммичено и запушено; `git ls-remote` совпадает с `HEAD`.
8. Пользователю честно сказано: анимация моделей играет в **PowerPoint 365 / 2021+**; в старых версиях, Keynote,
   Google Slides, LibreOffice и в браузерном просмотре Moodle будут статичные картинки (fallback). В песочнице
   PowerPoint нет — проверка идёт через повторный импорт glb в Blender.

## Грабли (уже наступали — не повторять)

**PowerPoint / pptx**
* Анимация объектов (node TRS) и shape keys в PowerPoint **не играют** — только кости (skin).
* Несколько действий на разных объектах → несколько glTF-анимаций; PowerPoint берёт одну. Нужна одна армутура, одно действие.
* Одинаковые имена 3D-моделей на слайде → PowerPoint удаляет модель.
* Draco-сжатие glb PowerPoint не читает.
* PowerPoint показывает PNG-растр, пока модель не перерисована, — растр должен совпадать с моделью (тот же поворот).

**Blender**
* `import bpy` без `/tmp/bstub` в `LD_LIBRARY_PATH` → ImportError по X11-библиотекам.
* Работает только Cycles (EEVEE требует OpenGL).
* Импортёр glTF добавляет служебную икосферу (форма костей) в коллекцию `glTF_not_exported` — если её не исключить,
  кадрирование считает её габариты и модель выходит крошечной.
* Хром и полированная сталь на тёмном фоне — почти чёрные; металл держать `roughness ≥ 0.3`.
* Модификаторы (bevel) и трансформации надо применить до экспорта, иначе веса/кости съезжают.
* `bpy.ops.object.join` без контекста не работает — `temp_override(active_object=…, selected_editable_objects=[…])`.
* В Blender 5 некоторые параметры glTF-экспортёра переименованы — фильтровать по `get_rna_type().properties`.

**Анимация**
* Частицы и мелкие существа в реальном масштабе не видны на слайде — увеличивать в 1.5–2 раза.
* Масштабирование тора по XY утолщает и «трубку» — кольца на воде делать тонкими (0.0036) и гасить по Z.
* Неудачный кадр 0 (пустая сцена) = неудачный постер и fallback — сдвигать фазу цикла.
* Знак угла: вращение вокруг +X отрицательным углом поднимает передний (−Y) край крышки; вокруг +Y отрицательным —
  поднимает правый (+X) край страницы.

**Сборка / окружение**
* `apt-get` недоступен; pip — только с `--break-system-packages`.
* `curl` к raw.githubusercontent может молча не скачать файл — проверять размер.
* Песочница откатывается — коммитить сразу; после отката `fetch --depth=1` + `reset`.
* `git fetch` без `--depth=1` и `timeout` может зависнуть.
* Параллельный `bash` и чтение файла, который он пишет, — гонка: читать после завершения команды.
* @sparticuz/chromium: `mod.default || mod`, библиотеки из `bin/al2023.tar.br` → `/tmp/al/lib`.
* Шрифт Gelasio без кириллицы.
* Поиск картинок отдаёт стоковые (Getty) — исторические изображения брать с Wikimedia Commons (общественное достояние)
  и подписывать.

## Пойманные на примере (train-ai/examples)

* **Открытая крышка обрезалась кадром.** Шкатулка D = 0.6: крышка на петле, поднятая на 105°, торчит вверх на ~D и
  выходит за описанную сферу габаритов покоя → в PowerPoint верх крышки срезан. Лечится геометрией (D = 0.38), а не
  камерой: раскадровка `anim_preview.py` кадрирует так же, как PowerPoint, — смотреть её перед сборкой.
