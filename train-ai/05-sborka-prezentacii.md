# 05. Сборка слайдов и содержание

## Слой разметки `lib.js`

Каждый слайд описывается **один раз**, а потом рендерится в два места: в нативный редактируемый pptx (pptxgenjs) и в
HTML → PNG для превью (headless Chromium). Поэтому превью совпадает с pptx почти пиксель в пиксель.

```js
const s = new Slide({ notes: "текст для заметок докладчика" });
s.bg = "0E080A";
s.img(path, { x, y, w, h, name });                       // дюймы, слайд 13.333 × 7.5
s.rect({ x, y, w, h, fill, fillT, line, lineT, lineW, radius, shape: "ellipse", dash, shadow, ag });
s.line({ x1, y1, x2, y2, color, lineT, width });
s.text([{ text, options: { bold, color, size, breakLine } }, …], { x, y, w, h, font: "head"|"body", size, color,
        align, valign, lineSpacingMultiple, charSpacing, name, ag });
s.model("chest", { x, y, s: 4.9, rot: [16, -28, 0], name: "!!m-chest", px: 780 });   // квадрат стороной s
toPptx(pres, slides);  toHtml(slides, assetsDir, fontsDir);
```

* `ag: N` — элемент появляется анимацией в группе N (см. 04).
* `name: "!!…"` — для Morph-совпадения между слайдами.
* `fillT`/`lineT` — прозрачность в процентах. pptxgenjs игнорирует `inset: 0` — использовать `margin: [0,0,0,0]`.
* Шрифты: заголовки Georgia (в превью Noto Serif — Gelasio не умеет кириллицу), текст Arial.

## Компоненты (`cantillon/build.js`)

| Компонент | Что рисует |
|---|---|
| `chrome(s, idx, kicker)` | фон, тонкая шкала прогресса с золотой заливкой, 3D-луидор-жетон, «кикер» раздела (`02 — ЧЕМ ЗАНИМАЛСЯ`), нижняя линия, футер, номер `03 / 10` |
| `stage(s, key, o)` | «экспонат»: световое пятно `glow.png`, два чертёжных кольца (сплошное и пунктир), мягкая тень `shadow.png`, сама 3D-модель, музейная подпись «ЭКСПОНАТ 03 — …» |
| `title(s, text, o)` | заголовок слайда (Georgia, 30–36 pt) |
| `fact(s, x, y, w, h, runs, {tag})` | плашка «★ САМОЕ ИНТЕРЕСНОЕ» — главный «вау-факт» слайда; есть на каждом слайде |
| `rows(s, items, o)` | нумерованные строки «заголовок + пояснение» (I, II, III / 03:00, Улики…) |
| `card(...)`, `label(...)` | карточки и надписи капсом |
| Схемы | таймлайны, цепочка «новые деньги → первые → рост цен → последние», 3 колонки классов, «эстафета идей» |

## Структура доклада (задание «взгляды учёного на предпринимательство»)

Проверенная структура на 10 слайдов (Кантильон):

1. Титул — кто это одной фразой + главный «вау-факт».
2. Где родился / контекст эпохи (факты карточками, портрет, загадка).
3. Чем занимался (карьера).
4. Ключевое событие, сформировавшее взгляды (пузырь Миссисипи, дуэль с Ло).
5. Главный труд (история книги).
6. Главная мысль (система, три класса).
7. Предприниматель по автору (определение + примеры + цитата).
8. Вторая большая идея (эффект Кантильона).
9. Вклад в теорию + «эстафета идей» до наших дней.
10. Загадка / итог / спасибо / источники.

По критериям оценки преподавателя (адекватность анализа, выводы, цитирование, форма) обязательно должны быть явно:
**контекст эпохи, кто/что повлияло на взгляды, суть теории, критическая оценка (сильные/слабые стороны),
собственные выводы на слайде, читаемый список источников.**

## Правила содержания

* Каждый слайд: заголовок-тезис (не «Биография», а «Ирландец из графства Керри»), 3–4 смысловых блока, одна плашка «★».
* **Не ставить непроверенные цитаты.** Цитата — только со ссылкой на главу/страницу; спорное помечать «по рассказу
  барона Гримма», «гипотеза М. Торнтона».
* Каждый факт → строка в `exports/<имя>-presentation-sources.md` (таблица «слайд | факт | источник»).
* Текст выступления пишется в `notes` слайда (живой разговорный язык, 40–60 с на слайд) и собирается в
  `exports/<имя>-presentation-script.md` (`writeScript()`), включая подсказки «экспонат делает то-то».
* Подпись экспоната описывает его анимацию и связь с темой: «Сундук открывается: ключ, бумаги, луидоры».

## Дизайн-правила (выстраданные)

* Заголовок 36 pt в ширину 7.4–7.6" переносится — для длинных брать 30–33 pt.
* Тёмный «музейный» фон, золото (`E3B663`), слоновая кость (`F5EFE6`), приглушённый (`BBAEA6`), акцент (`E8866A`).
* Модель справа (≈4.2–5 дюймов), текст слева в колонке ~7.3". На титуле модель большая (7.3").
* Мелкий текст не меньше 9 pt (кроме строки источников), иначе на проекторе не читается.
* Каждый слайд проверять по PNG-превью: наложения, переносы, «прилипание» заголовка к первой строке.

## Сборка

```bash
node build.js --preview            # pptx + preview/slide-XX.png
node build.js --preview --only=2,5 # превью только нужных слайдов
FAST=1 node build.js               # черновые растры в 1/3 разрешения
```

`prepareModels()` в `build.js`: собирает недостающие `.glb`, назначает id моделям, рендерит растры (только
изменившиеся — кеш по md5), призракам ставит `clear.png`, удаляет неиспользуемые растры. Затем
`toPptx → injectModels → injectTiming → dedupeMedia → zip DEFLATE 9 → writeScript → preview()`.

Итоговые артефакты кладутся в `exports/`: `.pptx`, `-script.md`, `-sources.md`, `-preview.jpg` (все слайды сеткой),
`-animations-preview.gif`.
