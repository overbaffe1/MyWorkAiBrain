# Шоурил «Музей оживших вещей» (3 слайда, топ-3 анимированных экспоната)

Три самые богатые анимацией 3D-модели коллекции, каждая на своём слайде:
корабль (23 кости), арфа (17 костей), свеча (10 костей).

Модели, растры и фоновые ассеты переиспользуются из `../cantillon`
(те же glb, те же повороты — Blender для сборки не нужен).
Движок — `../schumpeter` (`lib.js`, `pptx3d.js`, `node_modules`).

```bash
node build.js --preview   # → ../../exports/wow-3d-showreel.pptx + preview/slide-XX.png
```
