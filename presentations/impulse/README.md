# 3D-презентация: «Психология импульсивных трат» (13 слайдов, 13 анимированных экспонатов)

Проектное исследование «почему мы покупаем ненужное» — 3D-версия исходной презентации `ekonomika123.pptx`:
на каждом слайде стоит **настоящая 3D-модель PowerPoint** (`am3d:model3d`, `.glb` внутри pptx) со **своей анимацией
частей** (палец нажимает «купить», карта касается терминала, чек печатает себя, стрелка компаса времени бежит…).
Между слайдами — переход **Morph**: экспонаты влетают и улетают в 3D, а монета-жетон катится по шкале прогресса.

Движок тот же, что в `../schumpeter` и `../cantillon`: `lib.js`, `pptx3d.js`, `models/render.py`,
`models/rig.py`, `node_modules` из `../schumpeter`.

```bash
bash ../tools/setup-env.sh                                    # один раз: Blender, шрифты, node_modules
LD_LIBRARY_PATH=/tmp/bstub python3 models/make_models.py       # .glb → models/glb (все экспонаты)
python3 stage.py                                              # фон, свечение, тень → assets/
node build.js --preview                                        # → ../../exports/impulse-3d-presentation.pptx + preview/*.png
```

Проверка анимации без PowerPoint (рендерит то, что реально лежит в `.glb`):

```bash
LD_LIBRARY_PATH=/tmp/bstub FRAMES=6 PX=300 KEEP=1 python3 models/anim_preview.py phone card
python3 models/anim_sheet.py ../../exports/impulse-animations-preview.gif phone card ...
```

## Анимация внутри модели

PowerPoint проигрывает в `.glb` **только скелетную** (skinned) анимацию, поэтому у каждого экспоната **одна армутура
и одно действие**: каждая подвижная часть привязана к кости (`models/rig.py`), поза задаётся функцией от времени
`t ∈ [0, 1]` и запекается в ключи на 24 fps. `t = 0` и `t = 1` совпадают — цикл бесшовный, `pptx3d.js` находит анимацию
в `.glb` сам, прописывает `a3danim:embedAnim` и добавляет на слайд эффект «Сцена» с повтором до конца слайда.
Кадр 0 — это постер (и PNG-fallback), поэтому часть моделей стартует со сдвигом фазы: `anim((t + 0.26) % 1)`.

## Что проверено

* `[model] key: … KB, ~… tris, … bones, …s loop` — каждый экспонат напечатал бюджет при экспорте.
* Раскадровки `models/_anim/*.png` просмотрены: движение видно, цикл замкнут, детали не улетают за кадр.
* В `.glb` ровно одна анимация и один skin; в каждом слайде pptx есть `embedAnim` и эффект `presetID="100"`.
* PNG-превью всех 13 слайдов (`preview/`) просмотрены: переносы заголовков, наложения, мелкий текст.

Текст выступления — в заметках докладчика внутри `.pptx` и в `exports/impulse-presentation-script.md`,
список источников по слайдам — `exports/impulse-presentation-sources.md`.

**Важно:** анимация моделей играет в PowerPoint 365 / 2021+; в старых версиях, Keynote, Google Slides, LibreOffice
и в браузерном просмотре будут статичные картинки-растры (fallback внутри `mc:AlternateContent`).
