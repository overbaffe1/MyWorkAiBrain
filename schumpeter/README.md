# Шумпетер: 3D-презентация (v3)

Готовый файл: `exports/schumpeter-3d-presentation.pptx`. В нём 15 слайдов 16:9, текст можно редактировать, есть заметки докладчика.

- **Настоящие 3D-модели.** На каждом слайде стоит экспонат-модель (.glb, вставлен как PowerPoint 3D Model). Её можно вращать мышью.
- **Morph.** Модели на соседних слайдах называются одинаково (`!!m-<key>`). Поэтому при переходе текущий экспонат улетает влево с поворотом, а следующий влетает справа. Маленькая латунная шестерня катится по шкале прогресса и проворачивается на 144° за слайд.
- **Анимации появления.** Карточки и плашка «★ Самое интересное» выплывают по очереди автоматически, кликать не нужно.
- **Если 3D не поддерживается.** PowerPoint 2019/2021/365 и PowerPoint для Mac 16+ показывают модели в 3D. Keynote, Google Slides и старые версии вместо модели показывают её статичный рендер, а вместо Morph — Fade.

| | |
|---|---|
| `models/make_models.py` | процедурные модели в Blender (bpy) → `models/glb/*.glb` |
| `models/render.py` | Cycles-рендер модели с той же камерой, что у PowerPoint (растр-превью внутри .pptx) → `models/rasters/` (кэш) |
| `stage.py` | фон «сцены», свечение и тень под экспонатом → `assets/` |
| `lib.js` | слой разметки: одно описание слайда → .pptx (pptxgenjs) и HTML-превью |
| `pptx3d.js` | постобработка .pptx: вставка `am3d:model3d`, Morph, тайминги анимаций |
| `build.js` | содержание слайдов, заметки, хореография моделей |

```bash
npm install
pip install bpy                         # Blender как Python-модуль (нужен для моделей и растров)
python3 models/make_models.py           # пересобрать все модели (или: make_models.py globe king)
node build.js                           # .pptx + exports/schumpeter-presentation-script.md
node build.js --preview                 # плюс PNG-превью в preview/
```

`build.js` сам дособирает недостающие .glb и рендерит растры, которых нет в кэше. Ключ кэша — хэш модели, угла поворота и размера. Переменная `SAMPLES` задаёт качество Cycles (по умолчанию 64). С `FAST=1` получится быстрый черновик в низком разрешении.

Шрифты Georgia и Arial есть в Windows и macOS. В превью их заменяют Noto Serif и Arimo: метрики у них близкие или чуть шире, так что текст, который влез в превью, влезет и в PowerPoint.
